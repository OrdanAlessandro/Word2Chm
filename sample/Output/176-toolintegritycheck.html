toolIntegrityCheck

Ritorna o imposta la tipologia di controllo integrità utensile abilitata per l’elemento

  • 0=nessun controllo
  • 1=controllo integrità semplice: esegue il controllo dell’utensile corrente a fine file generando un allarme bloccante se il controllo fallisce
  • 2=controllo con cambio: esegue il controllo dell’utensile corrente a fine file marcando l’utensile come danneggiato nella tabella utensile e innescando, se previsto, il caricamento dell’utensile gemello
