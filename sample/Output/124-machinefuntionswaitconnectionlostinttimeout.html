Machine.Funtions.WaitConnectionLost(int timeout)

Attende la perdita di connessione con la macchina per il massimo tempo indicato

Parametri

  • timeout (intero>=0): timeout in millisecond di attesa del completamento dell’operazione. Se uguale a 0 la funzione ritorna immediatamente

Valore di ritorno: true se l’operazione si è completata con successo, false in caso di errore o timeout
