Cicli

I cicli permettono di eseguire una stessa porzione di codice più volte, finché una condizione è vera o per un numero definito di iterazioni.

for

for (var i = 0; i < 5; i++) {

log("Iterazione " + i);

}

  • Inizializzazione: var i = 0
  • Condizione di continuazione: i < 5
  • Incremento: i++

while

var quota = 0;

while (quota < 10) {

quota += 2;

log("Quota attuale: " + quota);

}

  • Il ciclo continua finché la condizione è vera.

do...while

var tentativi = 0;

do {

log("Tentativo: " + tentativi);

tentativi++;

} while (tentativi < 3);

  • Il blocco viene eseguito almeno una volta, anche se la condizione è falsa al primo controllo.
