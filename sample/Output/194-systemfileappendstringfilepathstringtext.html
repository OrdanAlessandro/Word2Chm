System.File.Append(string filePath, string text)

Appende il testo specificato alla fine di un file. Se il file non esiste, viene creato automaticamente.

È utile per registrare log, eventi o risultati in modo incrementale senza sovrascrivere il contenuto esistente.

Parametri

  • filePath (stringa): percorso del file da creare o modificare
  • text (stringa): testo da aggiungere alla fine del file. È responsabilità dello script includere eventuali caratteri di a-capo (\n) se desiderati.
