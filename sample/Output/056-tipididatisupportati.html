Tipi di dati supportati

Anche se non è necessario specificare il tipo, le variabili possono contenere diversi tipi di dato:

  • Numeri: interi o decimali
    var quota = 12.5;
  • Stringhe: delimitate da doppi o singoli apici
    var nomeBatch = "Batch1";
  • Booleani: true o false
    var abilitato = false;
  • Oggetti speciali o strutture dati: in base alle estensioni offerte da Skipper (es. accesso a parametri macchina o oggetti batch), possono esistere variabili strutturate o predefinite.
