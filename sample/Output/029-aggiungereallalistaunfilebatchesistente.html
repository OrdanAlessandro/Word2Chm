Aggiungere alla lista un file batch esistente

Per aggiunge alla lista un file batch esistente:

  1. Fare clic sul pulsante .
  1. Nella finestra “Apri”, indicare nella casella Nome file il nome del file batch da aggiungere alla lista; il file deve avere estensione “btc” come indicato nella casella Tipo file.
  1. Scegliere il pulsante Apri.

Le lavorazioni contenute nel file batch sono aggiunte sempre in coda alla lista.

Nota:

  1. Un file batch presente nella lista può essere compresso (tutte le righe sono nascoste) o espanso (tutte le righe sono visibili) con doppio clic sul nome del file.
  1. La riga che contiene un file batch può essere modificata solo nella colonna “ON” e nella colonna “Nrx”.
  1. Non è possibile aggiungere alla lista un file batch contenente altri file batch.
