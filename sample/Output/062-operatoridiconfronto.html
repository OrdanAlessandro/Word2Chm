Operatori di confronto

Utilizzati nelle condizioni (if, while, ecc.), servono per confrontare valori.

Operatore

Descrizione

Esempio

==

Uguaglianza (valore)

a == b

!=

Diverso

a != b

>

Maggiore

a > b

<

Minore

a < b

>=

Maggiore o uguale

a >= b

<=

Minore o uguale

a <= b

Nota: L'operatore == verifica solo il valore, non il tipo
